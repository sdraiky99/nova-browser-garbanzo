Bienvenido a Nova

Un navegador basado en Gecko: rápido, con vidrio y pensado para que las pestañas se sientan vivas. Te enseño lo esencial en un minuto.

Pestañas y pantalla dividida

El + viaja pegado a tu última pestaña. Pulsa Ctrl+T para abrir otra. Para ver dos webs a la vez, arrastra una pestaña a un lado de la ventana o usa el menú de la pestaña → «Dividir vista».

Tus datos y tus extensiones

Menú ☰ → Importar datos de otro navegador trae marcadores, historial y contraseñas. Las extensiones de Firefox se instalan desde addons.mozilla.org. Para herramientas de desarrollo usa F12.

Hazlo tuyo

En Ajustes → Apariencia eliges claro/oscuro, colores y fondos. Para ponerlo como navegador predeterminado abre Ajustes de Windows → Aplicaciones predeterminadas → Nova.
